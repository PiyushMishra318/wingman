// CAPABILITIES

Everything your system needs, unified.

7 Package Sources, One Scan

winget, Chocolatey, npm, pip, Steam, Windows Update, and ARP entries — Wingman queries them all in parallel and merges into a single scrollable inventory.

winget choco npm pip steam win update arp

Keyboard-First TUI

Navigate with arrow keys, filter packages, and trigger upgrades — all without leaving the terminal. Powered by Charm's Bubble Tea framework.

Silent -y Mode

Run wingman.exe -y to apply every supported upgrade non-interactively — perfect for scripts, scheduled tasks, and CI pipelines.

Parallel Discovery

All package managers are queried concurrently — no waiting for one to finish before the next begins. Benchmarked with go test -bench.

Auto Releases

Conventional commits on push to master trigger automated GitHub releases — always get the latest binary, no manual tagging required.

Start Menu Integration

Run wingman.exe -install-shortcut to pin Wingman to your Start Menu — launch the TUI without opening a terminal first.
