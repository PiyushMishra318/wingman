Why Wingman

  • ⊞ Every source, one scan winget, Chocolatey, npm, pip, Steam, Windows Update, and ARP entries — merged into a single inventory.
  • ⌨ Built for the terminal Filter, navigate, and upgrade with keyboard-first TUI — no clicking through six different apps.
  • ⚡ Silent when you need it Run wingman.exe -y to apply every supported upgrade without prompts.

How it fits your workflow

Parallel discovery across managers

Wingman scans package sources in parallel and merges results — so you see what's outdated without opening winget, choco, and npm separately.

winget choco npm pip steam win update arp scan complete · 142 packages

Interactive or hands-off

Launch wingman.bat for the full Bubble Tea TUI, or pass -y when you want every upgrade applied in one shot.

C:\> wingman.exe -y ▸ Upgrading Git 2.43.0 → 2.44.0 ▸ Upgrading eslint 8.56.0 → 9.0.0 ▸ 10 packages upgraded · 2 skipped

Get Wingman on Windows

Download the latest alpha pre-release from GitHub — run wingman.bat or wingman.exe locally.

Download release 
wingman.bat          # interactive TUI
wingman.exe -y       # upgrade all
go run ./cmd/wingman # dev
