Wingman

Terminal UI to discover and upgrade software on Windows — winget, Chocolatey, npm, pip, Steam, Windows Update, and ARP entries.

View on GitHub

Features

Scan installed software across package managers
Interactive TUI or non-interactive -y upgrades
Alpha pre-releases on GitHub
Download releasesSource

Quick start

wingman.bat          # interactive TUI
wingman.exe -y       # upgrade all
go run ./cmd/wingman # dev
